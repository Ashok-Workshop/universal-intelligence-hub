Important security boundary

A static browser app cannot conceal a GitHub token from the browser itself. Use a short-lived, repository-scoped fine-grained token, revoke it after syncing, and do not share this browser session. For stronger credential isolation, a small server-side GitHub App broker would be required; that adds infrastructure.
